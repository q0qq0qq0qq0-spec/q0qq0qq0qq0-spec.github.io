tj-playlist 개인정보처리방침

시행일: 2026년 10월 28일

  1. tj-playlist는 개발자 본인의 유튜브 계정에서 재생목록을 만들고 수정하기 위해서만 YouTube Data API를 사용합니다.
  2. 재생목록 정보 외의 개인정보는 수집하지 않으며, 어떤 데이터도 제3자에게 제공하거나 외부 서버로 전송하지 않습니다.
  3. Google 로그인 정보(인증 토큰)는 개발자 본인의 PC에만 저장되며, Google 계정 설정에서 언제든 접근 권한을 해제할 수 있습니다.
  4. tj-playlist의 Google API 사용은 Google API 서비스 사용자 데이터 정책을 따릅니다.
